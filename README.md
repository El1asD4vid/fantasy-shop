-Nombre del e-commerce: Fantasy Shop

-Descripción:
    Fantasy Shop es una aplicación web de e-commerce dedicada a la venta de objetos inspirados en mundos de fantasía. La tienda ofrece productos como espadas, pociones, bastones, escudos, etc. La aplicación permite visualizar la información de cada producto, consultar su categoría, precio, stock disponible y descripción, además de agregarlos a un carrito de compras que actualiza automáticamente la cantidad de productos y el stock restante.

-Registro Principal:
| Campo       | Tipo de dato |
| ----------- | ------------ |
| idProducto  | Entero       |
| nombre      | Alfanumérico |
| categoria   | Alfanumérico |
| precio      | Real         |
| stock       | Entero       |
| descripcion | Alfanumérico |

-Clave del Registro elegida: idProducto.
    Se eligió idProducto como clave principal porque identifica de manera única cada producto. Esto evita duplicados y facilita operaciones como la búsqueda, actualización del stock y administración del catálogo.

Enlace de la app e-commerce: https://el1asd4vid.github.io/fantasy-shop/
